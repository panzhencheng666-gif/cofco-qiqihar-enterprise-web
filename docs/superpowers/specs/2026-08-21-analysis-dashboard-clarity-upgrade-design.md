# 三页经营分析看板清晰度升级设计

## 目标

继续升级产情分析、市场分析和供需平衡，使三页在不增加业务指标、不改变服务端计算口径的前提下，具有更明确的信息层级、更丰富且符合关系的图形、更紧凑的留白和统一的业务色彩语义。

## 数据与实时边界

- 市场分析只使用已审核市场与既定物流字段。
- 产情分析只使用已审核产情字段，以及同一权威快照内已经返回的供需库存结果。
- 供需平衡只显示服务端基于已审核产情、市场库存和既定物流字段计算的结果。
- 前端只进行图形坐标与版式计算，不新增业务公式、业务比率或静态数值。
- 数据查询、筛选和实时刷新继续使用现有 `useObservableAnalysisSnapshot` 与实时事件链路。
- 缺失值不补零；单期不绘制趋势；不足两个有效组成项时不绘制环图。

## 信息架构

### 顶部范围区

标题、业务副标题与刷新按钮形成稳定左栏；产品、年份、月份、授权范围、四级地区与重置组成右侧紧凑范围栏。宽屏保持一体化工具栏，窄屏再分行，不保留大块空白标题行。

### 指标与统计范围

核心指标卡继续显示真实值、单位与核定来源数，并按业务角色使用青绿、蓝、土金、酒红四类克制色彩。原“数据覆盖”改为“统计范围”，不再单独占用空卡，压缩为状态区内的“地区、调查对象、采用记录”三项业务计数。

### 自动收拢网格

共享网格记录实际卡片数。辅助区只有两张卡时自动铺满两列，三张卡时使用三列；条件卡缺失后不保留空白槽位。

## 图形语义

### 市场分析

- 收购价与销售价使用价格差异连接图，直接标出两个核定价格和核定价差。
- 采购量、销售量使用零基线竖向柱图。
- 市场库存与质量长字段保留适合长标签的横向或区间结构。
- 流通成本使用竖柱图；包装数量使用竖柱，包装占比使用环图。
- 质量最低值、平均值、最高值按同一质量字段组成区间图，不再堆成长条列表。

### 产情分析

- 面积、产出和库存去向使用零基线竖柱图，并显示单位与刻度基线。
- 成本构成、灾损和种植意向使用横向对比，长名称不截断。
- 质量最低值、平均值、最高值使用区间图。

### 供需平衡

- 供需流向桥继续直接使用服务端计算结果。
- 供需总量使用零基线竖柱图。
- 库存分层使用横向对比；只有生产端与企业端期末库存均有效时才显示构成环图。
- 统计范围与质量状态使用紧凑计数，不生成无分母的“覆盖率”。

## 视觉系统

- 核定实际：青绿 `#287a6f`。
- 业务对比与流向：蓝色 `#3d78a8`。
- 成本与投入：土金 `#a46f2a`。
- 缺失与关注：酒红 `#8e2934`。
- 卡片使用白底、浅灰边框和轻阴影；去除无业务意义的装饰渐变。
- 图表补齐零基线、最高刻度、单位、端点或区间图例；不增加解释段落。

## 验收标准

- 三页宽屏顶部范围区高度明显收敛，无大块空白标题行。
- 市场页至少同时出现价格差异图、竖柱图、环图和质量区间图。
- 产情页同时出现竖柱、横向对比和质量区间图。
- 供需页同时出现流向桥、竖柱和库存分层；不完整构成不绘制环图。
- “统计范围”含义明确且不独占空卡；两卡辅助区不保留第三列。
- 图表数值、单位、基线或区间端点完整可见，无页面横向溢出。
- Node 24 定向测试与构建通过，63182 和 8090 健康，浏览器无相关警告或错误。
