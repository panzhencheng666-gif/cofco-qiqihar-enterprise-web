# 样本网络地图联动与去卡片化治理工作台设计

日期：2026-08-23

状态：用户已确认设计方向，等待书面规格复核

适用范围：总揽监测地图、样本点治理工作台、产情分析、市场分析、供需平衡，以及这些页面与 8090 权威服务之间的实时同步。

## 1. 决策摘要

本轮修正两个相互关联的问题：

1. 进入乡镇后，地图必须直接展示该乡镇全部行政村的设计样本覆盖标识，不再要求用户先点击行政村、再到右侧栏开启图层。
2. 样本点治理从“多张卡片纵向堆叠”重构为“固定模块导航、连续状态摘要、单一主表、右侧处理抽屉”的企业工作台。

设计样本点、稳定样本身份、年度在网资格和月度业务记录继续保持四层分离，不修改已经确认的数据语义：

- 设计样本点：2,332 个行政村参照，不分年份；
- 稳定样本身份：现实中的长期调查对象，不因月份或年度重复创建；
- 年度在网资格：说明稳定样本在某一年是否正式纳入网络；
- 月度业务记录：产情、市场、物流等每次填报形成的永久记录。

## 2. 当前问题与根因

### 2.1 地图图层入口错误

现有地图把样本图层初始值和地区切换后的重置值设为“只看现有”。图层按钮又位于点击行政村后才出现的详情栏中。因此乡镇级接口即使已经返回全部设计村数据，地图仍会主动隐藏它们。

这不是设计样本数据缺失，而是图层控制的位置、默认值和重置规则错误。

### 2.2 治理页面缺少任务主线

现有治理内容依次堆叠年度网络、坐标上传、任务历史、审核队列和身份治理。用户无法快速判断：

- 当前在管理哪一种样本对象；
- 应当先处理身份、坐标还是年度资格；
- 哪些是日常查询，哪些是需要审核的任务；
- 一次操作会影响地图、年度名单还是业务记录。

问题不是功能不足，而是信息架构没有围绕业务对象和操作顺序组织。

## 3. 地图交互设计

### 3.1 常驻图层工具栏

在地图主视图区放置常驻的紧凑图层工具栏：

```text
样本网络：对照显示｜现有样本｜设计样本
```

- “对照显示”为乡镇级和行政村级默认模式；
- 图层选择不再依赖右侧详情栏；
- 地区、产品、年度或实时数据刷新不得擅自重置用户当前图层；
- 切换到新层级时，如当前模式在该层级不适用，系统按本设计的层级规则降级，并给出一行说明。

右侧详情栏只负责展示所选地区或样本点的内容，不再承担全局图层控制。

### 3.2 分层展示规则

| 地图层级 | 默认展示 | 设计样本表达                                                  |
| -------- | -------- | ------------------------------------------------------------- |
| 市级     | 区县汇总 | 显示设计村总数、已核验坐标数、当年覆盖数，不铺开 2,332 个标识 |
| 区县级   | 乡镇汇总 | 按乡镇显示设计覆盖数量，不铺开全县行政村标识                  |
| 乡镇级   | 对照显示 | 自动显示该乡镇全部行政村设计覆盖标识，同时显示当年现有样本点  |
| 行政村级 | 对照显示 | 保留全乡镇设计覆盖标识，突出当前村，其他村降低亮度            |

用户从乡镇进入行政村后，地图上下文不能被清空。当前行政村使用高亮边界和高亮标识，其他行政村设计标识保持可见但降低对比度。

### 3.3 图标与坐标真实性

地图严格区分“覆盖标识”和“精确点位”：

- 未通过权威坐标核验时，在行政村内部使用设计覆盖标识，表示“该行政村属于设计样本体系”；该标识不能描述为精确经纬度点。
- 权威坐标核验通过后，才允许显示设计样本精确位置图标。
- 年度现有样本点继续沿用系统现有的产情类、市场类和其他正式业务图标，不更换成新的装饰图标。
- 设计样本使用独立、稳定的设计参照图标，不与产情或市场现有点混淆。
- 同一稳定现有样本点在多个业务月份填报，只更新其业务记录集合，不增加地图身份图标。

地图图例必须同时解释：设计覆盖、设计精确位置、产情现有点、市场现有点和区域级现有点。

### 3.4 右侧详情栏

右侧栏随选择对象变化：

- 点击行政村：显示行政村设计参照状态、坐标核验状态、当年现有样本数和覆盖关系；
- 点击设计覆盖标识：显示设计村基本信息和坐标治理状态；
- 点击现有样本点：显示稳定身份、所在地层级、当年在网状态和已审核业务摘要；
- 点击空白或关闭：收起详情栏，但不改变图层模式。

右侧栏不再重复放置“只看现有、只看设计、对照显示”按钮。

## 4. 样本点治理工作台

### 4.1 导航归属

样本点治理是持续性的主数据和年度网络管理能力，不属于“已办事项”。正式入口移至平台运营管理部的“样本点管理”。“我的工作”只保留分配给当前用户的待审核或待处理任务，并可跳转到对应治理对象。

### 4.2 页面骨架

治理页面使用连续工作台，不采用卡片网格、卡片套卡片或大面积圆角面板。

页面从上到下固定为：

```text
面包屑
页面标题＋主要操作
连续状态摘要
模块标签页
筛选与批量工具栏
单一主表
分页
右侧详情或处理抽屉
```

连续状态摘要最多显示四项：

```text
设计样本 2,332｜坐标已核验｜本年度在网｜待处理任务
```

它是一条连续信息带，不拆成四张卡片。

### 4.3 四个业务模块

模块标签固定为：

1. **样本点名册**：查询和治理稳定样本身份、名称、对象类型与所在地层级；
2. **设计样本点**：查询 2,332 个行政村参照及其坐标来源、核验状态和覆盖关系；
3. **年度在网样本**：生成候选、确认继续使用、新增、暂停、移除、提交和独立审核；
4. **待办审核**：集中处理坐标修正、身份合并和年度网络审核任务。

每次只展示一个模块的主表。历史记录放在对象详情内的“操作记录”标签，不单独占据一整块首页空间。

### 4.4 操作流程

#### 年度交接

```text
选择年度 → 生成候选名单 → 核对继续/暂停/新增 → 提交审核 → 发布年度网络
```

生成下一年度候选名单只引用上一年度稳定样本身份，不复制产量、价格、库存或任何月度业务数据。

#### 新增现有样本

产情、市场或物流填报识别到新调查对象时：

```text
身份匹配 → 未匹配时创建稳定样本候选 → 归入当年网络 → 独立审核 → 正式在网
```

同一稳定样本在不同月份的不同业务数值属于不同业务记录，不属于重复样本。

#### 坐标修正

```text
选择待修正对象 → 填写权威来源和新坐标 → 校验 → 提交审核 → 原位更新稳定身份 → 地图同步刷新
```

坐标批量文件属于批处理方式，不作为普通用户理解治理架构的首页主入口。导出、上传、失败行重试放入“设计样本点”模块的批量操作菜单；审核任务统一进入“待办审核”。

## 5. 实时同步联动

### 5.1 唯一数据源

63182 地图、63200 治理工作台及产情分析、市场分析、供需平衡都从 8090 权威接口读取，不建立前端私有副本，不用静态演示数据覆盖服务端结果。

页面查询统一使用以下业务范围：

```text
地区＋产品＋年度＋当前用户权限
```

月度业务记录仍按自身月份保存；年度样本网络只控制年度资格，不改变业务记录期间。

### 5.2 事件驱动刷新

沿用现有 `/api/v1/business-events/stream` 事件流。以下业务动作成功后必须产生能够被页面识别的业务事件：

- 稳定样本身份创建、合并或状态变化；
- 设计样本坐标审核通过；
- 年度候选名单生成；
- 年度成员新增、暂停、移除；
- 年度网络提交、退回或发布；
- 与样本网络相关的业务记录审核发布。

事件到达后：

1. 地图失效并重新读取受影响地区的对照数据和图标；
2. 治理工作台重新读取当前模块的摘要和主表；
3. 三个分析页面重新读取样本网络覆盖摘要；
4. 用户当前地区、产品、年度、标签页、表格筛选和地图图层保持不变；
5. 若刷新失败，保留当前数据并明确标记“数据可能已更新，正在重连”，不得静默显示旧数据为最新。

当前页面完成写操作后立即本地刷新；事件流负责其他页面、其他窗口和其他登录用户的同步。两者不能互相替代。

## 6. 视觉与可用性约束

- 不使用卡片网格表现治理模块；
- 不使用卡片套卡片；
- 不用大面积留白、阴影和圆角制造层级；
- 主表至少占可用内容区的 70%；
- 状态使用文字、窄标签和表格列，不为每种状态建立独立方块；
- 主要操作固定在标题栏或表格工具栏，行级操作固定在最右列；
- 高风险操作必须有明确文字、影响说明和二次确认；
- 所有技术状态码转成业务中文，页面不显示接口名、数据库字段名或开发术语；
- 1440px 和 1920px 桌面宽度下首屏均能看到状态摘要、模块标签、筛选和主表表头；
- 键盘焦点、无障碍名称、空状态、加载状态和错误状态必须完整。

## 7. 实施边界

- 不重做总揽监测地图的既有三维视觉架构；
- 不改变现有样本点业务图标；
- 不复制或清理数据库数据；
- 不伪造 2,332 个经纬度；
- 不把设计样本点写入年度业务事实表；
- 不把月度重复填报误判为重复样本身份；
- 不进入云端、生产或 `main`；
- 本轮继续在 `feature/20260823-sample-network-comparison` 功能分支完成并通过 PR 门禁。

## 8. 验收标准

### 地图

- 进入任一乡镇，无需点击行政村即可看到该乡镇全部行政村设计覆盖标识；
- 图层工具栏在地图主视图始终可见，默认选择“对照显示”；
- 点击行政村后，当前村高亮，其他村设计标识仍保留；
- 切换地区、产品、年度和实时刷新不会擅自重置图层；
- 未核验坐标不显示为精确点；已核验坐标与所属行政村一致；
- 年度现有样本点继续使用既有业务图标。

### 治理工作台

- 页面不再位于“已办事项”；
- 页面不存在纵向卡片堆叠和卡片套卡片；
- 四个模块通过标签切换，每次只有一个主表；
- 普通用户能够从页面顺序判断当前对象、状态和下一操作；
- 年度交接、身份治理、坐标修正和审核任务不会混在同一表中。

### 实时联动

- 一处写操作成功后，当前页面立即更新；
- 8090 业务事件到达后，63182、63200和三个分析页面刷新受影响数据；
- 自动刷新保留当前操作上下文；
- 事件流断开或刷新失败时显示可恢复状态，不假装数据最新。

### 工程验证

- Node 24 定向测试和三仓相应门禁通过；
- 63182、63200与8090健康；
- 受管运行副本与源码发布清单 SHA-256 一致；
- 浏览器完成乡镇进入、图层切换、行政村突出、治理模块切换和跨页实时更新验收；
- 浏览器无相关警告、错误、遮挡、溢出或滚动陷阱。

## 9. 自检结果

- 文档无待定项、占位内容或示例业务数值；
- 地图层级规则、坐标真实性和图标语义一致；
- 治理模块按业务对象分离，未把不同生命周期重新混合；
- 实时同步同时覆盖当前页面写后刷新和跨页面事件刷新；
- 范围只包含样本网络地图、治理工作台及其分析覆盖联动，不扩大到云端或生产部署。
