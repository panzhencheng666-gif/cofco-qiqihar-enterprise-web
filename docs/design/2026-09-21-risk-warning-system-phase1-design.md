# 风险研判预警系统第一阶段设计

## 阶段目标

在不改变现有业务工作台流程、数据和权限行为的前提下，增加一个与“业务工作台”平级的独立“风险研判预警”应用入口，并交付可独立构建、可直接访问、可安全回退的系统外壳。

本阶段完成条件：

- `/risk/` 是独立 Vite 入口和 React 挂载点，不复用业务工作台路由状态。
- 现有平台头部只增加一个普通链接；删除该链接与独立入口即可完整回退。
- 新页面只显示真实状态。后端风险 API 尚未接入时，显示“当前暂无可研判数据”和“尚未建立”，不展示模拟风险、虚构模型或假指标。
- 页面覆盖研判、处置、训练、评估、知识、数据源和审计的信息架构，但本阶段只开放总览中的安全空状态。
- 现有业务工作台相关测试继续通过。

## 隔离边界

- 前端：新增 `risk/index.html` 与 `src/risk/**`，不把风险路由加入现有业务工作台的 `FormalRoute`。
- 导航：只修改共享的 `EnterprisePlatformHeader`，增加 `/risk/` 链接和 `risk` 激活态。
- 数据：本阶段不读取现有业务页面的前端状态，不写任何业务接口。
- 后端：沿用已经建立的 `risk` schema 治理底座；本阶段不新增后端接口或迁移。
- AI：页面不会声称模型已训练、已上线或已经产生判断。训练流水线与推理服务属于后续独立阶段。

## 页面结构

设计基准：`docs/design/risk-warning-primary-screen-concept.png`。

- 顶部：延续平台品牌和账号区；主导航显示业务工作台、风险研判预警、我的任务和按权限显示的系统管理。
- 左侧：研判总览、风险事件、研判中心、预警处置、模型训练、模型评估、知识库、数据源、审计追踪。
- 主区：今日研判空状态和两个有效导航动作：配置数据源、查看训练策略。
- 下方：模型治理区域，正式模型、候选模型、最近训练均以未建立状态呈现。
- 右侧：研判详情空状态，说明未来只展示风险证据、反面证据、不确定性和建议措施。

## 视觉系统

- 主色：`#12324a`；辅助深青：`#1e5a61`；强调金：`#b99145`。
- 背景：白色与冷灰，不使用渐变、玻璃拟态或装饰性统计卡片。
- 圆角：6px 至 10px；边框细而明确。
- 风险红仅用于真实语义状态，本阶段空状态不使用风险红。
- 所有文字、链接和控件由 React/HTML/CSS 渲染，概念图不进入运行页面。

## 后续阶段

1. 风险只读查询 API 与权限契约。
2. 数据源接入、证据快照和风险事件列表。
3. 规则研判、AI 辅助研判与人工反馈闭环。
4. 每日训练候选流水线、离线评测、影子运行和审批晋级。
5. 私有模型推理服务、模型注册表、监控和回滚。

每个阶段独立验收，不能以前端空壳代表模型、训练或生产发布已经完成。
