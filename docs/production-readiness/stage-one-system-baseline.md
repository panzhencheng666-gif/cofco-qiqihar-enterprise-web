# 阶段一：唯一系统与追踪基线

本文件只定义阶段一边界和证据入口，不宣称阶段二、阶段三、身份、云、性能、安全或最终上线通过。机器可核验的完整清单位于 [`stage-one-system-baseline.json`](./stage-one-system-baseline.json)。

## 唯一入口与运行组件

- 本地正式验收唯一用户入口：`http://127.0.0.1:63182/`。
- 业务 API `8090`、总揽渲染器 `63200` 和 PostgreSQL `5432` 均为内部组件，不是用户验收入口。
- `63200` 只通过 `63182` 的 `/overview-monitoring` 与 `/overview/` 同源路径提供总揽内容。
- 企业生产域名尚待批准，已指派给阶段十的平台部署负责人；批准域名只能指向业务 Web 根入口。
- 历史替代端口不得进入运行清单、启动器、用户文案或制品。

| 组件         | 责任仓   | 入口/端口    | 所有权                                  |
| ------------ | -------- | ------------ | --------------------------------------- |
| 桌面启动命令 | Backend  | 只打开 63182 | 指向正式 runtime，不读取 Desktop 同名仓 |
| 本地栈监督者 | Backend  | 无用户端口   | LaunchAgent 与 `scripts/start-local.sh` |
| 业务 Web     | Web      | `63182 /`    | 唯一用户入口、同源网关、业务导航        |
| 总揽渲染器   | Frontend | 内部 `63200` | 地图几何、指标、地区钻取和样本点展示    |
| 业务 API     | Backend  | 内部 `8090`  | 领域、事务、授权、审计与后台任务        |
| 业务数据库   | Backend  | 内部 `5432`  | PostgreSQL/PostGIS 与 Flyway            |

## 追踪清单边界

JSON 清单逐项记录：

- 6 个一级业务应用与当前全部二级菜单；
- 壳层、列表、表单、保存、提交、审核、退回、照片、总揽、供需、报告和身份治理动作族；
- `src/business` 44 个非测试 TSX 中 382 个按钮、链接、筛选/输入与弹框源码节点，并以源码摘要校验清单新鲜度；
- 业务记录、单据审核质量发布、待办、导入任务和供需结果的状态集合；
- 产情、市场、物流 XLSX，履职报告、业务报告与照片文件流；
- 异步导入、SSE 连接、Flyway 和本地进程监督任务；
- 三仓全部受控 `docs/specs`、`docs/superpowers/specs` 和 `docs/superpowers/plans` 历史来源。

清单中的 `IMPLEMENTED` 只表示实现位置已经登记；`PARTIAL` 与 `NOT_EVIDENCED` 明确保留后续缺口。任何一项都不能替代阶段二/三的真实数据库、真实浏览器、角色或业务验收。

## 可重放阶段一门禁

在三仓候选提交完成且工作树干净后执行：

```bash
npm run stage1:run -- --output-dir <全新的外部证据目录>
```

执行器在一个 Run 中锁定三个分支和 SHA，顺序运行：

1. Backend `mvn clean verify`；
2. Frontend `npm run verify`；
3. Web `npm run verify`；
4. 三仓制品定位、SHA-256、候选不变性与结束时干净检查。

输出目录包含每仓独立日志、`snapshot.json` 和 `SUMMARY.md`。只有所有命令、制品与候选不变性均为 `PASS`，阶段一三仓门禁快照才是 `PASS`。

## 阶段一判定规则

| 门禁                | 责任           | 直接证据                                      |
| ------------------- | -------------- | --------------------------------------------- |
| S1-1 三仓边界       | 发布负责人     | Run 快照中的分支、SHA、上游与干净状态         |
| S1-2 唯一生产路径   | Web 架构负责人 | `63182 /` 唯一入口，内部端口全部已认领        |
| S1-3 架构与迁移顺序 | 三仓架构负责人 | Frontend/Web 依赖门禁、Backend 架构与迁移测试 |
| S1-4 空库迁移       | Backend/DBA    | clean Run 内 `FlywayMigrationReplayTest`      |
| S1-5 三仓同一 Run   | 发布负责人     | 外部证据目录中的原子快照和独立日志            |
| S1-6 完整追踪       | 产品与 QA      | 机器清单与源码/历史来源一致性测试             |

阶段一退出结论必须引用新鲜 Run，不得引用旧混合报告目录或仅凭代码存在作出 `PASS`。
